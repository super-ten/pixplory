LLM
Large Language Model
大語言模型
AI 的“大腦引擎”。通過海量參數計算概率分布來生成內容。
Agent
AI Agent
智能體
Codex等能直接控制、调用多种工具的AI智能化工具。
Skills
AI Skills / Toolset
技能 / 工具集
賦予 Agent 的具體能力模塊。例如“聯網查閱資料”、“自動發郵件”或“調用渲染器引擎”。
MCP
Model Context Protocol
模型上下文協議
Anthropic 推出的開源標準。被譽為 AI 的“萬能數據插頭”，通過標準化協議讓大模型安全、合規地穿透軟件壁壘，讀取本地文件或雲端系統數據。
CLI
Command Line Interface
命令行界面
極客與開發者偏愛的純文本控制台。當前很多硬核 AI（如 Claude Code）直接在此環境運行，以最高權限接管機器操作。
RAG
Retrieval-Augmented Generation
檢索增強生成
讓 AI 在回答前先去指定的外部知識庫中“翻書找依據”，是目前解決 AI 事實性“幻覺”最主流的技術架構。
Vibe Coding
-
氛圍/意圖編程
【最新範式】 人類像“導演”一樣提供意圖和審美，AI 負責語法與實現。標誌著創作者從“工匠”向“指揮家”轉變。
Markdown
-
純文本標記語言
一种轻量级的标记语言，可用于在纯文本文档中添加格式化元素，設定Rules。
IDE
‌Integrated Development Environment‌
集成开发环境
它把程序设计全过程所需的各项功能集合在一起，为程序设计人员提供完整的服务。
workflow
1. 節點（Input/Task）2. 路由（Routing/Path）3. 規則（Rules/Logic）
工作流
把複雜的任務拆解成有規律的輸送帶」，讓事情能順著預設好的軌道自動跑完。
Git
-
分散式版本控制系統
遊戲存檔、版本更新內容、歷史紀錄
Task
-
任務執行列表
要求 AI 模型去執行並完成的特定目標或功能。
PRD
Product Requirements Document
產品需求文檔
是將模糊的「AI 願景」轉化為可落地的「工程指令」，確保技術團隊在模型邊界、數據需求與用戶價值之間達成共識的導航地圖。
React
點擊編輯...
React 應用
基于React JavaScript，用 React 代码实现html网页的同时，能同步开发 iOS 和 Android 原生应用。目前AI-IDE生產優選。
canvas
點擊編輯...
视觉画布
Canvas 是一個能隨時幫你改稿、可視化、以畫布連接邏輯思維的AI畫布。
FDE
Forward Deployed Engineer
前沿部署工程
Ai驻场交付，全链路闭环，AI技术与落地集成；能力点：1.全栈设计技术2.行业业务洞察3.客户沟通能力。
